# Базис

Vue 3 + Vite, KaTeX и собственный двухэтапный симплекс-метод на Python. Python работает локально в Web Worker через Pyodide / WebAssembly; сервер вычислений не требуется.

## Запуск

```bash
npm ci
npm run dev
```

```bash
npm run build
```

Публикуйте содержимое `dist` как статический сайт. Файлы Python в `public/python` автоматически копируются из установленного npm-пакета Pyodide при `npm ci`, перед запуском и перед сборкой. Крупные бинарные зависимости не хранятся в Git. Первый расчёт загружает среду Python (~12 МБ); следующие используют ту же среду.

## Возможности

- Чёрно-белый интерфейс, геометрическая анимация с ручным управлением.
- История решений в виде квадратных карточек: создание, переименование и удаление проектов.
- Отдельные исходные данные, результаты и шаг работы для каждого проекта; автоматический перенос задачи из прежней версии.
- Четыре шага ввода, 1–20 переменных и ограничений, знаки = / ≤ / ≥, max / min.
- Вставка коэффициентов диапазоном, заполнение пустых значений нулями.
- Собственный Python-алгоритм без готовых оптимизаторов: искусственный базис, удаление избыточных строк, правило Бланда.
- Таблицы итераций, формулы пересчёта, автоматический и учебный просмотр.
- Решение, проверки допустимости, абсолютные невязки; переключение приближённого дробного представления в таблицах.
- Автосохранение проектов в localStorage, хранение предыдущего расчёта внутри каждого проекта для сравнения.
- Краткий отчёт через «Скачать PDF» → «Сохранить как PDF» в диалоге печати.

## Практические пределы

Вычисления выполняются с double precision и допуском 1e-9. Дроби — приближённое представление чисел с ограничением знаменателя 1000, не рациональная арифметика. Невязка проверяет допустимость и не является гарантированной границей ошибки оптимума. Предел — 500 итераций на этап. Для крайне плохо обусловленных задач результат требует дополнительной проверки.

Основные файлы: `src/App.vue`, `src/style.css`, `public/solver.py`, `public/worker.js`.

## Известные недоработки

- Единый абсолютный допуск 1e-9 может давать неверный ответ при очень маленьких коэффициентах.
- Достижение лимита на первом этапе пока ошибочно трактуется как несовместность ограничений.
- Вкладка «Погрешности» выводит невязки; перенос погрешностей исходных данных и оценки ошибок найденных значений по требованиям лабораторной ещё не реализованы.

Репозиторий содержит текущую рабочую версию интерфейса; перечисленные ограничения требуют исправления перед сдачей лабораторной.
